## What I'm Building

### [Reqsh](https://github.com/hars-21/reqsh) - Interactive HTTP Shell

A developer-focused HTTP REPL built from scratch in Rust.

I am designing the internals and working on:

* Lexer and parser architecture
* HTTP request construction
* Session state and variable interpolation
* CLI interaction and response rendering
* Error handling and testing

**43+ GitHub stars and feedback from real users.** The driving force for building and maintaining [reqsh](https://www.reqsh.dev).

> Building Reqsh is my way of learning Rust by solving real engineering problems instead of following isolated tutorials.

---

### [Paperdrill](https://github.com/hars-21/paperdrill) - The exchange built for developers

A paper-trading exchange built to understand how trading systems work end to end.

The system includes:

* Matching engine
* Order lifecycle and execution
* Order book state
* Real-time market data streaming using WebSockets
* Redis-based service communication
* Persistent orders and fills
* Backend APIs & Trading interface

Paperdrill has **real users actively using it and requesting features**, which has shifted development from simply building features to responding to actual product feedback.
